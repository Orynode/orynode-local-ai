# Security policy

Copyright (c) 2026 Orynode

## Safe defaults

- Keep TurboFieldfare bound to `127.0.0.1`.
- Do not expose the local inference endpoint to the public internet.
- V1 LAN sharing has no accounts; only use it on a trusted network.
- Do not run untrusted tool calls generated by a model.
- Report suspected vulnerabilities privately to Orynode maintainers before
  public disclosure.

The current version is an early local development preview and has not received
an independent security audit.
