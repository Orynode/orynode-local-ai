# Contributing

Thank you for your interest in Orynode Local AI.

## Current policy

The MIT license still allows anyone to fork, modify, and redistribute this
software.

At this stage we are **not merging external pull requests** into the Orynode
upstream. Please do not open PRs for features, refactors, or documentation edits
right now. Existing or new pull requests may be closed without merge.

This is a contribution-process choice, not a change to the license.

## What you can do

- Open an [Issue](https://github.com/Orynode/orynode-local-ai/issues) for bugs, install problems, or ideas
- Include environment details and `npm run doctor` output when reporting install/start failures
- Do not include API tokens, conversation contents, or private files

This policy may change later. Until then, Issues-only feedback is preferred.
