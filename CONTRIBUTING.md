# Contributing

Thank you for your interest in Orynode Local AI.

## Current policy

At this stage we are **not accepting external pull requests or code contributions**.

Please do not open PRs for features, refactors, or documentation edits right now.
Existing or new pull requests may be closed without merge.

## What you can do

- Open an [Issue](https://github.com/Orynode/orynode-local-ai/issues) for bugs, install problems, or ideas
- Include environment details and `npm run doctor` output when reporting install/start failures
- Do not include API tokens, conversation contents, or private files

This policy may change later. Until then, Issues-only feedback is preferred.
